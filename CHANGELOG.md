## 1.0.0

- Initial release. Packages the Lights Out SWE gated pipeline as a plugin for GitHub Copilot CLI, Claude Code, and VS Code Copilot.
- Five agents: analyze, explore, reconcile, review, verify.
- One skill: build-discipline.
- Twelve commands including `/lo-swe-init` for bootstrapping the harness into a fresh repo.
